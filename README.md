
# AgendaYA - TP6 Testing Automatizado (M04 & M06)

Proyecto base de frontend y suites de pruebas automatizadas (E2E con Cypress y Unitarias con Jest) para los módulos de Booking Público (M04) y Notificaciones (M06).

## Requisitos previos

- Node.js (v18+ recomendado)
- Servidor local (extensión Live Server de VS Code o paquete `serve`)

## Instalación

Clonar el repositorio e instalar las dependencias:

```bash
npm install
```
